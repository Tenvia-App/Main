    FAQ

    About the project

    Can I download Tenvia yet?

    A test build for Android is available on GitHub (about 1.2 GB, including the on-phone AI). This newest build has not been tested on a phone yet. It is test software for trying the app, not for real emergencies. Install it at your own risk. How to install and test it.

    Will I need an internet connection?

    No. Tenvia works fully offline, including its AI, which runs on your phone. The current test build asks for internet permission only so the app can talk to the AI running on the same phone; it makes no other connections. The finished app is planned to drop that permission.

    Is Tenvia open source?

    Yes. The code, the guide content and every AI test result are public on GitHub under the Apache License 2.0.

    Will Tenvia be free?

    Yes. The goal is to make basic preparedness guidance accessible without a subscription.

    Can Tenvia contact emergency services?

    No. Tenvia is a preparedness and guidance app. For immediate help, call 911 (or your local emergency number) directly. In the US, call or text 988 for a mental-health crisis.
