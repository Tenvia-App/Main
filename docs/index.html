    Become a tester

    Help make Tenvia better

    Tenvia is in early testing, and real practice chats are the most useful thing you can give. You need an Android phone with about 2.5 GB of free space. It takes about 10 minutes.

    Step-by-step install guide

    On an iPhone? Tenvia is Android only for now, but you can still help: email tenvia.testchats@gmail.com with the subject "iPhone tester" and write the first message you'd type if you were really stuck, in your own words. Please make it up and leave out personal details.

    Questions, or want to hear when a new version is out? Email tenvia.testchats@gmail.com.

    1. Install the test app. Follow the step-by-step guide. Android will warn you because Tenvia isn't on the Play Store yet.
    2. Pretend you're in trouble. Turn on airplane mode, open the chat and describe a made-up situation in your own words: lost on a trail, car stuck in snow, water rising, a snake bite, a gas smell at home. Send 3 or 4 messages.
    3. Tap "Send this chat". Check the text, remove anything personal, then send it with your email app. The address is filled in for you.
    4. Only practice. Never use the test app in a real emergency. If you are in danger, call 911.

    FAQ

    About the project

    Can I download Tenvia yet?

    A test build for Android is available on GitHub (about 1.2 GB, including the on-phone AI). It is test software for trying the app, not for real emergencies. Install it at your own risk. How to install and test it.

    Will I need an internet connection?

    No. Tenvia works fully offline, including its AI, which runs on your phone. The current test build asks for internet permission only so the app can talk to the AI running on the same phone and, when you happen to be online, check GitHub for a newer test version (it never downloads anything by itself; see the privacy page). It makes no other connections. The finished app is planned to drop that permission.

    Is Tenvia open source?

    Yes. The code, the guide content and every AI test result are public on GitHub under the Apache License 2.0.

    Will Tenvia be free?

    Yes. The goal is to make basic preparedness guidance accessible without a subscription.

    Can Tenvia contact emergency services?

    No. Tenvia is a preparedness and guidance app. For immediate help, call 911 (or your local emergency number) directly. In the US, call or text 988 for a mental-health crisis.
